---
name: Movies Reco
role: Lead developer
description: A mobile movie recommendation app for a group, built from each member's tastes.
mission: Help a group pick a movie everyone will enjoy, based on each member's preferences rather than a random compromise.
problem: "Every user has their own tastes: the app needs to recommend movies to a single person, but also to combine several profiles into a shared group profile."
method: Each user builds a list of their favourite movies, which feeds their profile. They can then compare their profile with the others to generate a shared group profile, or see the movies recommended to them personally. Built with TypeScript.
result: "In progress. This project taught me about recommendation algorithms, machine learning basics and how to prepare a dataset for this specific purpose, as well as the strengths and limitations of Claude Code."
---
