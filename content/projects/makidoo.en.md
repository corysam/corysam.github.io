---
name: Makidoo
role: Fullstack developer, technical lead
description: A white-label video application serving several client brands from a single codebase.
mission: Enable Dream And Achieve to deploy its Makidoo product under each client's identity, without duplicating code or multiplying the environments to maintain.
problem: Every new client required visual and functional adjustments. Without a dedicated architecture, these variations turned into forks that were hard to keep in sync, and into technical debt.
method: Nest.js APIs, a React / Redux front-end reworked to reduce existing debt, a per-brand configuration mechanism, deployments orchestrated with Docker Swarm and GitLab CI, and administration of the development and production Linux servers. Support for external contractors.
result: A white-label solution run in production for nearly two years, stabilised environments and an improved user experience on the front-end.
