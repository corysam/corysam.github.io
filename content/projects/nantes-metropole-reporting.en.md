---
name: Reporting tool — Nantes Métropole
role: Java developer (Daveo assignment)
description: A Java tool collecting data through the Microsoft API, paired with Eclipse BIRT for visualisation.
mission: Give the local authority a reliable way to extract data from the Microsoft ecosystem and present it as usable reports.
problem: The required data was scattered and only reachable through the Microsoft REST API. No existing pipeline could consolidate it or confirm that the project was technically viable.
method: Built a Java tool to query the API, integrated it with Eclipse BIRT to generate reports, then ran a test campaign to validate feasibility before scaling up.
result: A working tool and a documented feasibility study, used as the basis for deciding the project's next steps.
